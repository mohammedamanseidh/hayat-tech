# HAYAT TECH website

Single-file site. Everything is in `index.html`.

## Update content
Open `index.html` and edit the block near the top marked `EDIT YOUR CONTENT HERE`
(phone, email, stats, systems, services, project captions). Keep the quotes and commas.

## Publish changes
```
git add .
git commit -m "describe the change"
git push
```
Netlify (or GitHub Pages) redeploys automatically.
